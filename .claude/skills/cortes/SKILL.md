# Cortes

Entrada: transcrição com tempos (ou o vídeo, se houver transcrição disponível).

1. Escolha de 3 a 7 trechos de 20–60s que funcionem sozinhos: começam com uma ideia completa, têm um momento de impacto e terminam sem depender do resto.
2. Para cada corte entregue: tempo de início e fim, **novo gancho** para os 3 primeiros segundos (pode ser uma frase do próprio trecho movida para o começo), título, legenda com hashtags e o motivo da escolha.
3. Ordene do mais ao menos promissor.
4. Se houver `ffmpeg`, gere o comando de corte vertical 9:16 para cada trecho.
5. Sugira onde colocar legenda animada e zoom.
